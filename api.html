API

Use the same analyzer behind SiteTrace.

The public endpoint accepts a website URL and returns uptime, speed, SSL, SEO, security header checks, a score, and actionable recommendations.

Base URLhttps://sitetrace-api.onrender.com
Public endpointPOST /analyze
AuthNot required for manual scans
curl -X POST https://sitetrace-api.onrender.com/analyze \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://example.com",
    "locale": "en"
  }'
{
  "status": "success",
  "analyzed_url": "https://example.com/",
  "final_url": "https://example.com/",
  "status_code": 200,
  "response_time_ms": 243,
  "response_time": "243ms",
  "score": 89,
  "page_context": "standard",
  "summary": {
    "pass": 10,
    "warning": 3,
    "fail": 0,
    "uptime": 4,
    "seo": 8,
    "security": 3
  },
  "ssl": {
    "issuer": "Google Trust Services",
    "expires_at": "2026-08-20T12:00:00.000Z",
    "days_remaining": 108
  },
  "checks": [
    {
      "category": "uptime",

}

Request body

urlRequired. Public http or https URL.
localeOptional. Use en or es for recommendations.

Notes
