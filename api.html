How SiteTrace Works

We built SiteTrace to be the simplest way to know if your clients' websites are healthy. No complicated setup required.

1. Add a site

Enter the URL of any website you manage. No agents to install, no code to modify. SiteTrace works from the outside, just like a visitor would.

2. SiteTrace checks it

We instantly scan for uptime, SSL expiry, broken SEO basics, security warnings, and more — everything that tends to break quietly.

3. You get a clear status

See a simple health score and a prioritized list of anything that needs fixing. Each issue includes context so you know exactly what to do next.

4. Share the result

Generate a beautiful, client-ready report to prove the value of your maintenance. Use status pages to give clients live visibility into site health.

What SiteTrace looks for

Focused on problems most likely to hurt trust, leads, or client confidence.

Uptime & response

Detect outages and slowdowns before clients notice.

SSL certificate

Days until expiry, valid chain, HTTPS redirect.

SEO basics

Title, meta description, canonical, H1, noindex, OG tags.

Domain expiry

Days until the domain registration expires.

Content changes

Homepage title, keywords, or page content that changed.

Security headers

Missing CSP, HSTS, X-Frame-Options, and other signals.
